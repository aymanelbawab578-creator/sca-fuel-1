# 🚀 SCA Fuel - نظام متابعة استهلاك الوقود

## 📱 نبذة عن المشروع

تطبيق Flutter احترافي لمتابعة استهلاك الوقود لأسطول هيئة قناة السويس.

**الإصدار:** 1.0.0  
**الحالة:** ✅ جاهز للاستخدام  
**اللغة:** العربية (RTL)

---

## ✨ الميزات الرئيسية

### 📊 التقارير الذكية
- 📅 تقرير يومي شامل
- 📈 تقرير الفترة الزمنية  
- 📦 تقرير الكميات والتفويلات
- 🎨 نظام تلوين ذكي (أحمر/أصفر/أخضر)
- 📥 تصدير Excel و PDF

### ⚙️ إدارة الإعدادات
- 👤 إدارة بيانات المستخدم
- 🔐 تغيير كلمة المرور الآمن
- 🌙 الوضع الداكن المحفوظ تلقائياً
- 💾 النسخ الاحتياطي والمزامنة
- 📱 تصميم متجاوب

### 🌍 دعم اللغة العربية
- 100% نصوص عربية
- اتجاه RTL تلقائي
- تنسيق تواريخ عربي

## 🚀 البدء السريع

### المتطلبات:
```
Flutter SDK >= 3.0.0
Dart SDK >= 3.0.0
IDE (VS Code أو Android Studio)
```

### التثبيت:
```bash
# 1. انتقل لمجلد المشروع
cd frontend

# 2. حمّل الحزم
flutter pub get

# 3. شغّل التطبيق
flutter run

# أو على المتصفح
flutter run -d chrome
```
